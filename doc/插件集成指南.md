# zenoh-link-iroh 插件集成指南

> 从独立状态机到可被 zenohd 加载的 cdylib 插件——完整步骤

---

## 1. 架构回顾

```
zenohd (路由器进程)
  │
  ├─ -P rest          → libzenoh_plugin_rest.so    (HTTP API)
  ├─ -P storage       → libzenoh_plugin_storage.so  (持久化)
  └─ -P iroh_link     → libzenoh_plugin_iroh_link.so  ← 我们要构建的
       │
       ├─ IrohLinkManager  (实现 LinkManagerUnicastTrait)
       │   ├─ dial(locator)    → IrohTransportLink
       │   └─ listen()         → 后台 accept 循环
       │
       └─ IrohTransportLink (实现 LinkUnicastTrait)
           ├─ write()    → LinkStateMachine.write() → Iroh SendStream
           ├─ read()     → LinkStateMachine.read()  → Iroh RecvStream
           ├─ tick()     → LinkStateMachine.tick()  → 超时检测
           └─ on_path_change() → Iroh Endpoint 回调
```

## 4. 插件实现

```rust
use zenoh_plugin_trait::Plugin;
use zenoh_plugin_trait::Runtime;

pub struct IrohLinkPlugin {
    // Iroh endpoint (全局共享)
    endpoint: Option<iroh::Endpoint>,
}

impl Plugin for IrohLinkPlugin {
    fn name(&self) -> &str { "iroh_link" }
    fn version(&self) -> &str { env!("CARGO_PKG_VERSION") }

    fn start(&mut self, runtime: &Runtime) -> Result<(), Box<dyn Error>> {
        let session = runtime.session();
        let config = runtime.config();

        // 创建 Iroh Endpoint
        let relay_url = config.get("transport.link.iroh.relay_url")
            .unwrap_or("https://iroh.network/relay");
        let endpoint = iroh::Endpoint::builder()
            .relay_url(relay_url.parse()?)
            .alpns(vec![b"zenoh-link-iroh/1.0".to_vec()])
            .bind()
            .await?;

        // 注册 LinkManager 到 zenoh transport 层
        let manager = IrohLinkManager::new(endpoint.clone());
        session.register_link_manager("iroh", manager)?;

        // 启动心跳
        tokio::spawn(heartbeat_loop(endpoint.clone(), session.clone()));

        Ok(())
    }

    fn stop(&mut self) -> Result<(), Box<dyn Error>> {
        // 关闭 Iroh endpoint
        if let Some(ep) = self.endpoint.take() {
            ep.close().await?;
        }
        Ok(())
    }
}
```

## 5. LinkManager 实现

```rust
use zenoh_link_commons::LinkManagerUnicastTrait;
use zenoh_link_state::link_state::LinkStateMachine;

pub struct IrohLinkManager {
    endpoint: iroh::Endpoint,
    active_links: Arc<Mutex<HashMap<String, Arc<IrohTransportLink>>>>,
}

#[async_trait]
impl LinkManagerUnicastTrait for IrohLinkManager {
    async fn new_link(&self, locator: &Locator) -> Result<Box<dyn LinkUnicastTrait>> {
        // 解析 iroh/<node_id>
        let node_id = locator.address();
        let link = IrohTransportLink::connect(
            self.endpoint.clone(),
            node_id,
        ).await?;

        self.active_links.insert(node_id.to_string(), link.clone());
        Ok(Box::new(link))
    }

    async fn del_link(&self, locator: &Locator) -> Result<()> {
        self.active_links.remove(locator.address());
        Ok(())
    }
}
```

## 6. 加载验证

```bash
# 编译插件
cargo build --release

# 复制到 zenoh 插件目录
cp target/release/libzenoh_plugin_iroh_link.so ~/.zenoh/lib/

# 启动 zenohd 并加载插件
zenohd \
  -P iroh_link \
  -l iroh/<your_node_id> \
  -e iroh/<peer_node_id>
```
